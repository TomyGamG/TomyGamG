## ANPR — Reconocimiento Automático de Patentes

Proyecto de Computer Vision orientado al **reconocimiento automático de matrículas vehiculares argentinas**.

**Tecnologías:**

`Python` `YOLO` `Ultralytics` `PaddleOCR` `EasyOCR`

**Pipeline:**

```text
Imagen / Cámara
       ↓
Detección de vehículo
       ↓
Detección de patente
       ↓
Procesamiento de imagen
       ↓
OCR
       ↓
Validación del formato
       ↓
Patente reconocida
```
El proyecto combina detección de objetos, procesamiento de imágenes y OCR para automatizar la identificación de patentes.
